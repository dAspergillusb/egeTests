Как пользоваться кабинетом администратора?

В данном разделе администратор может управлять пользователями. Создавать новых, изменять существующих, удалять.

Для создания нового пользователя нужно в конце списка нажать на кнопку Создать пользователя, после чего создастся новая область для заполнения данных о новом пользователе и выбора прав доступа (администратор, учитель, ученик).

В списке пользователей можно менять их параметры (имя, фамилия, права доступа, пол, класс (для ученика), состояние, новый пароль). Для изменения параметров пользователя нужно нажать на кнопку Изменить. После внесений изменений нужно нажать на кнопку Сохранить. Также можно удалить пользователя, нажав на кнопку Удалить.

Если изменять/создавать пользователя не требуется, то можно нажать на кнопку Отменить.

В этом разделе администратор может массово добавлять пользователей в базу данных (например при добавлении всего класса) или полностью перезаписать всю базу.

Для перезаписи или добавления пользователей необходимо создать csv-файл с данными (его легко можно создать в табличном редакторе). Он должен выглядеть следующим образом:

Первой строкой должны идти заголовки для столбцов в строгой последовательности: firstname, lastname, sex, school_class, username, password, rank.

Что означают эти заголовки: 

  firstname    - Имя;
  lastname     - Фамилия;
  sex          - пол;
  school_class - класс и литерал класса;
  username     - имя пользователя;
  password     - пароль от учетной записи;
  rank         - права доступа (student, teacher, admin).

Далее идут данные пользователей. Для учителя или администратора класс не нужен, поэтому область между двумя ";" можно оставить пустой.

Пример готового csv-файла: 

  firstname;lastname;sex;school_class;username;password;rank
  Admin;;;;admin;admin;admin
  Teacher;;;;teacher;teacher;teacher
  Test;User;no sex;11Z;user;user;student

В этом разделе администратор может посмотреть список активных сессий пользователей (1) или активных сессий тестов для учеников (2), создавать/очищать новые базы данных пользователей или вопросов (3), а также переключаться между базами данных (4).

В разделе (1) администратор может просматривать активные сессии пользователей. В каждой ячейке есть кнопка для удаления этой сессии. Она становится активной, когда её время выходит. На случай, если остались висячие некоторые сессии (например пользователь не вышел из кабинета, а просто закрыл кладку и не вернулся к ней), можно их удалить. В ячейке, где отображается текущая сессия администратора будет сверху ячейки сообщение Текущая сессия.

Раздел (2) похож на предыдущий. Внутри карточки отображается основная информация по тесту: время начала, время окончания, id-вопросов в тесте, ответы к этим вопросам (0 - ответ не дан).

В разделе (3) администратор может добавлять новые или очищать существующие базы данных пользователей или вопросов. Сначала в выпадающем меню нужно выбрать тип базы данных или опцию "Новая база". Затем нажать на кнопку Очистить базу данных, если выбран тип базы. Если выбрана опция создания, то необходимо выбрать тип создаваемой базы и задать имя для неё, затем нажать на кнопку Добавить базу данных.
